FIELD NOTE / INCIDENT RESPONSE

Incident Handling, Traffic Analysis & IOC Triage

Structured analysis exercises using the incident lifecycle, network capture tools and threat intelligence.

Incident documentation

I used a five-W framework to record the actors, event, affected environment, timing and likely cause in a simulated healthcare ransomware scenario. I also organized the response into detection and analysis, then containment, eradication and recovery.

Traffic analysis

Separate activities introduced Wireshark for packet-capture analysis and tcpdump for command-line traffic capture and filtering.

Indicator triage

A SOC scenario involved checking a suspicious email-attachment file hash with VirusTotal, then documenting why the alert warranted additional investigation.

Takeaway

Clear notes, evidence-driven triage and reproducible investigation steps matter as much as tool familiarity.

Based on entries in the “Incident handler's journal.” These were guided training exercises, not live incident-response assignments.
